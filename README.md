# 🐶 Pet Business AI Assistant

An AI-powered pet business application built with Python, RAG,
semantic search, local/cloud LLM integration, puppy inventory,
customer lead capture, and business analytics.

## Features

- AI-powered RAG chatbot
- Semantic search using Sentence Transformers
- Puppy inventory management
- Puppy image cards
- Exact puppy ID lookup
- Customer lead capture
- Customer enquiry database
- Business analytics dashboard
- Streamlit web interface

## Technologies

- Python
- Streamlit
- Pandas
- Sentence Transformers
- Scikit-learn
- Ollama / LLM
- CSV data
- RAG
